# Epic 免费游戏监控 · 云湖机器人推送

基于 ScriptCat（脚本猫）的定时脚本：定时查询 Epic 官方免费游戏促销接口，
发现新的「本周免费」或「下周预告」时自动推送到云湖机器人。

相比通过视频或第三方资讯获取信息，官方接口在促销开始前一个完整周期就会返回预告内容，
不需要等待内容创作与发布，因此能更早拿到消息。

## 特性

- **信息更早**：直接读官方促销接口，比视频、资讯类渠道提前一个周期拿到预告
- **双批次推送**：分别推送「本周免费」与「下周预告」，换周当天即可发现变化
- **批次去重**：以「促销类型 + 开始时间」作为批次标识，同一批次只推送一次；
  同批次内临时追加或更换游戏时会推送阵容调整提示
- **自动过滤**：默认只保留游戏本体，忽略 DLC、附加内容与礼包
- **区域可配**：语言与地区可切换，国区、美区商品与价格各自独立
- **自包含**：单文件脚本，零第三方依赖，不使用 `@require` 加载外部库
- **失败不丢消息**：仅在推送成功后记录批次，网络异常时下次执行会重新尝试

## 快速开始

### 1. 安装

在 ScriptCat 中新建脚本并粘贴脚本内容，或把下面的地址加入脚本猫的「导入脚本」：

```
https://raw.githubusercontent.com/yimu56/epic-free-games-notify/main/epic-free-games-notify.user.js
```

### 2. 配置

打开脚本，修改文件顶部的配置区：

```js
const CONFIG = {
  LOCALE: 'zh-CN',              // 语言
  COUNTRY: 'CN',                // 地区，决定可见商品与价格货币

  YUNHU_TOKEN: '',              // 云湖机器人 token
  YUNHU_RECV_ID: '',            // 接收者 ID
  YUNHU_RECV_TYPE: 'group',     // group 为群聊，user 为私聊
  // ...
};
```

在云湖控制台创建机器人后，控制台会给出「机器人发送消息链接」，
形如 `https://chat-go.jwzhd.com/open-apis/v1/bot/send?token=xxxxxxxx`，
其中 `token=` 之后的内容即 `YUNHU_TOKEN`。接收者 ID 填群号
（`YUNHU_RECV_TYPE` 为 `group`）或用户 ID（`YUNHU_RECV_TYPE` 为 `user`）。

### 3. 验证

脚本开启后等待 cron 触发，或在脚本猫面板上点击「运行一次」手动执行。
首次运行默认只记录当前批次、不推送，避免刚开启就收到历史消息。

## 配置项

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `LOCALE` | `zh-CN` | 接口语言，可取 `zh-CN`、`en-US` 等 |
| `COUNTRY` | `CN` | 接口地区，决定可见商品与价格货币，可取 `CN`、`US` 等 |
| `YUNHU_TOKEN` | 空 | 云湖机器人 token，必填 |
| `YUNHU_RECV_ID` | 空 | 云湖接收者 ID，必填 |
| `YUNHU_RECV_TYPE` | `group` | `group` 为群聊，`user` 为私聊 |
| `PUSH_CURRENT` | `true` | 是否推送「本周免费」批次 |
| `PUSH_UPCOMING` | `true` | 是否推送「下周预告」批次 |
| `ONLY_BASE_GAME` | `true` | 仅推送游戏本体，忽略 DLC、附加内容与礼包 |
| `INCLUDE_DESCRIPTION` | `true` | 是否附带商品简介 |
| `DESC_MAX_LEN` | `200` | 简介截断长度 |
| `CONTENT_TYPE` | `markdown` | `markdown` 自动适配深浅色；`html` 支持封面图 |
| `PUSH_COVER` | `false` | 是否输出封面图，仅 `CONTENT_TYPE` 为 `html` 时生效 |
| `FIRST_RUN_PUSH` | `false` | 首次运行是否推送当前批次 |
| `KEEP_BATCHES` | `12` | 本地保留的批次记录数量上限 |

## 推送效果

```
**Epic 本周免费游戏（10-08 23:00 ~ 10-15 23:00）**

**《虎视眈眈 (Out of Sight)》**　原价 ¥53.00
https://store.epicgames.com/zh-CN/p/out-of-sight-b96ca8

**《TerraScape》**　原价 ¥53.00
https://store.epicgames.com/zh-CN/p/terrascape-2b12b1

领取入口：https://store.epicgames.com/zh-CN/free-games
```

预告批次的消息标题为「Epic 下周免费游戏预告」，正文结构一致。

## 工作原理

1. 请求 Epic 官方促销接口
   `https://store-site-backend-static.ak.epicgames.com/freeGamesPromotions`
2. 从 `data.Catalog.searchStore.elements` 中取出折扣为 100%（即免费）的商品，
   并按 `offerType` 过滤掉非游戏商品
3. 按「促销类型 + 开始时间」把商品归入批次，批次标识形如 `current|开始时间` 与 `upcoming|开始时间`
4. 与本地记录的批次比对：
   - 出现新批次 → 推送
   - 同批次内商品 id 集合发生变化 → 推送阵容调整提示
   - 批次与商品均未变化 → 跳过
5. 推送成功后记录该批次及其商品 id 集合

**同一款游戏会推送两次**：先作为「下周预告」推送一次，换周之后作为「本周免费」再推送一次。
这是设计预期，两者是不同阶段的信息。

批次记录保存在脚本猫的脚本存储中，键名为 `epic_free_games_state`。
切换商店地区后旧记录自动失效，会重新建立基线。

## 定时策略

元数据中的 `@crontab * 9-23 once * *` 表示：每天 09:00-23:59 之间首次触发时执行一次，当天只执行一次。

Epic 换周的时间点是北京时间周四 23:00，脚本通常在换周后的下一个触发点即可发现变化。

浏览器关闭期间定时脚本不会执行，`once` 写法可以保证当天只要开机就会补上这一次。
如需固定时间执行，改成 `0 9 * * *`（每天 09:00），代价是错过该时刻当天不再执行。

## 已知限制

- **商店网页无法直接抓取**：Epic 商店页面受 Cloudflare 保护，直接请求返回 403，
  因此脚本统一使用官方促销接口取数，不需要登录也不需要 Cookie。
- **接口地区决定商品范围**：国区与美区的免费阵容、价格货币存在差异，
  默认使用国区（`COUNTRY: 'CN'`），需要美区数据时改为 `US`。
- **未公布的商品不会出现**：接口只返回已配置促销的商品，
  在官方正式公布之前，预告中的商品不会出现在返回结果里。
- **云湖图片消息不支持外链**：图片消息只能使用云湖「图片上传」接口返回的 `imageKey`，
  无法直接引用外部图片地址。因此默认只推送文字，封面图仅在 `CONTENT_TYPE` 为 `html`
  时以外链形式展示。
- **云湖成功码为 1**：云湖接口正常返回 `{"code": 1}`，而非常见的 `0`。
- **依赖浏览器常驻**：ScriptCat 定时脚本需要浏览器运行期间才会触发；
  若需 7×24 执行，可考虑用 CloudCat 将脚本部署到服务器。

## 测试

`test/run-test.js` 通过注入模拟的 GM 接口，在 Node 中执行脚本源码：

- 提供合成数据的请求回放固定数据，用于精确构造换周、阵容调整、地区切换等分支
- 未提供合成数据的请求走真实网络，验证官方接口可用性与解析逻辑
- 对云湖的请求被拦截，仅记录请求体并回放成功响应，不会发送到真实群聊

```bash
node test/run-test.js
```

覆盖场景：首次运行记录批次、非游戏商品过滤、数据未变化时不推送、换周推送本周与预告两条、
换周后不重复推送、同批次阵容调整提示、切换地区重建基线、配置缺失跳过执行、真实接口可用性。
